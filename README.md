# 独立商品图工坊 v2.2.2 在线更新

本部署包用于把 v2.2.2 发布到 `97tg7kt8ws-pixel/VT-st`。

## 本次更新

- 1500 个背景场景全部改为中文结构化生图提示词，其中服装类 540 个。
- 每条提示词统一包含：当前场景、最终结构、场景结构、固定光线、固定材质、固定颜色、构图执行、禁止新增和完整场景描述。
- 固定唯一承托面，只替换商品轮廓外明确可编辑的背景像素。
- 不扩图、不补边、不缩图、不拉远、不重新取景、不重新居中、不移动商品。
- 禁止新增人物、手脚、商品、家具、道具、包装、文字水印及画外内容。
- 加入完整的普通二手卖家手机连续随拍规则，保留偏心、边线歪斜、曝光不均、自然噪点和真实使用痕迹。
- 物理质检增加主体移动、缩放、裁切、扩景、第二承托面、商业布景和假背景识别。
- 保留 v2.2.1 的原目录安全更新、自动重启、失败回滚与软件位置显示。

## GitHub 发布顺序

1. 创建 Release，Tag 必须为 `v2.2.2`。
2. 上传 `IndependentProductStudio_Windows_x64_v2.2.2.zip` 到该 Release。
3. 确认 Release 文件可下载后，将本部署包中的 `version.json` 和 `README.md` 上传并覆盖仓库根目录同名文件。
4. `version.json` 必须最后更新。
