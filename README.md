# 独立商品图工坊 v2.2.4 在线更新

本部署包用于把 v2.2.4 发布到 `97tg7kt8ws-pixel/VT-st`。

## 本次更新

- 服装生成前自动识别真人站立穿着、衣物平铺、衣物悬挂或有支撑摆放状态。
- 原图拍摄状态优先于内置场景和追加背景词，禁止背景要求改变穿着、平铺或悬挂状态。
- 真人站立穿搭自动排除床面、沙发、座椅、桌面和软垫，只允许真实地面、低绒地毯或户外铺装。
- 锁定原人物、身体裁切、站姿、双脚位置、鞋、饰品及服装结构，防止重新塑形或替换。
- 所选背景不兼容时，优先切换到相同环境、相同光线下的物理兼容场景。
- 生成后使用高清原图与结果图进行物理质检，重点检查站床、悬浮、鞋底穿模、错误透视及主体变化。
- 物理质检默认最多自动重新生成 3 次。
- 保留 1500 个中文结构化场景、追加背景词最高优先级和全部已有功能。

## GitHub 发布顺序

1. 创建 Release，Tag 必须为 `v2.2.4`。
2. 上传 `IndependentProductStudio_Windows_x64_v2.2.4.zip`。
3. 确认 Release 文件可下载后，将本部署包中的 `version.json` 和 `README.md` 覆盖到仓库根目录。
4. `version.json` 必须最后更新。
