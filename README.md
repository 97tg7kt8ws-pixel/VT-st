# 独立商品图工坊 v2.2.3 在线更新

本部署包用于把 v2.2.3 发布到 `97tg7kt8ws-pixel/VT-st`。

## 本次更新

- 平铺提示词加入真人正上方手机拍摄判断，模拟成年人站在商品上方约 70–110 厘米使用手机 1 倍主摄拍摄。
- 检查商品重心、柔软开口自然塌落、承托面纹理遮挡、纹理连续性和短柔贴面阴影。
- 禁止衣物被隐形人体、衣架、气流或看不见的支架撑成立体状态。
- 生成后物理质检增加真人现场复现五项判断，不增加额外质检调用次数。
- 追加背景提示词提升为背景生成最高优先级。
- 追加词与内置地点、承托面、颜色、材质、纹理、光线或氛围冲突时，以追加词为准。
- 商品主体、原构图、画幅、真实物理规律和禁止新增规则仍保持锁定。
- 保留 v2.2.2 的 1500 个中文结构化场景和全部已有功能。

## GitHub 发布顺序

1. 创建 Release，Tag 必须为 `v2.2.3`。
2. 上传 `IndependentProductStudio_Windows_x64_v2.2.3.zip`。
3. 确认 Release 文件可下载后，将本部署包中的 `version.json` 和 `README.md` 覆盖到仓库根目录。
4. `version.json` 必须最后更新。
