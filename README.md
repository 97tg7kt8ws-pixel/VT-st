# 独立商品图工坊在线更新

此仓库用于发布独立商品图工坊 Windows x64 便携版更新。

## 当前版本

- 版本：2.0.3
- 软件包：`IndependentProductStudio_Windows_x64_v2.0.3.zip`
- SHA-256：`b7c3451a0490afb87b0466c5a7f82142a3074c13d70e9f5cbd7314e4f13895b7`
- 安装方式：完整解压后双击 `IndependentProductStudio.exe`

## v2.0.3 更新内容

- 修复在线更新安装完成后软件没有自动重新启动的问题。
- 安装前主动释放单实例锁，避免新版被误判为重复启动。
- 等待并清理旧版残留的 Electron 渲染进程和工作进程。
- 新版启动后进行存活检测；启动过早退出时自动重试，最多 5 次。
- 新版始终无法启动时恢复旧版本并尝试重新打开，防止更新后软件不可用。

> 从 v2.0.2 升级到 v2.0.3 时，安装动作仍由 v2.0.2 的旧更新助手执行；如果安装后没有自动打开，请手动双击一次软件。进入 v2.0.3 后，后续版本将使用修复后的自动重启流程。

## 软件内更新地址

```text
https://raw.githubusercontent.com/97tg7kt8ws-pixel/VT-st/main/version.json
```

软件会检查版本、下载 Release 中的 ZIP、验证文件大小与 SHA-256，然后自动替换并重启。更新失败时会恢复旧版本。

## 发布顺序

发布新版本时，先创建对应版本的 GitHub Release 并上传 ZIP，确认可以下载后，最后更新仓库根目录的 `version.json`。
